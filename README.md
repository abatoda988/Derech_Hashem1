# דרך השם – מערכת סינון והגנה

שלד Android/Kotlin מוכן לפתיחה ב-Android Studio ולדחיפה ל-GitHub.

## מה כבר בפנים
- מסך ראשי בסיסי.
- מסך הגנה בעיצוב שסיכמנו.
- נעילת מגע מלאה למשך 2 שניות.
- Accessibility Service עם `notificationTimeout=0` כדי לצמצם השהיה.
- Device Administrator רגיל.
- זיהוי Package Installer.
- זיהוי מסכי אבטחה/מנהלי מכשיר לפי טקסט, כולל **"הגדרות אבטחה נוספות"**.
- GitHub Actions שמבצע build אוטומטי של APK.

## חשוב
החסימה של "הגדרות אבטחה נוספות" נעשית דרך Accessibility, ולכן היא תלויה במבנה/טקסט של מסך ההגדרות במכשיר. שמות המסכים יכולים להשתנות בין יצרנים וגרסאות Android, ולכן יש להרחיב את רשימת המילים/זיהויים לאחר בדיקה על המכשיר האמיתי.

`0ms` אמיתי אינו מובטח באנדרואיד; הפרויקט מכוון למסלול זיהוי->חסימה קצר ככל האפשר.
